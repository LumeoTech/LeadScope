# LeadScope
O LeadScope é uma plataforma que combina Scanner de Empresas e CRM Comercial. Permite encontrar empresas, consultar dados reais, organizar leads, acompanhar negociações, agendar reuniões e gerenciar propostas. Desenvolvido com Java, Spring Boot, React, TypeScript e PostgreSQL, busca otimizar a prospecção e a gestão comercial.
